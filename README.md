# SindhBio 9

SindhBio 9 is a Class 9 Biology study and exam-preparation website for Sindh Board students. It is built around the Sindh Textbook Board (STBB) Class 9 Biology textbook and includes a solution bank, MCQs with instant feedback, differences tables, interactive diagrams, past papers, and mock-exam tools.

## Live website

https://bio-9th.vercel.app/

## Main features

- Complete Solution & Model Answer Bank for all 9 textbook chapters
- MCQs with instant correct/wrong feedback and short explanations
- Simple MCQ progress score and mistakes-to-review list
- Search and chapter filters
- Bookmarks for revision
- Differences Hub and interactive diagrams
- Sindh Board Class 9 Biology past papers
- Mock paper generator and online exam runner
- Mobile-friendly responsive layout

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Important note

Unofficial study aid based on the STBB Class 9 Biology textbook. Always verify with your textbook.

The site does not require Gemini or a browser-exposed API key; the unused Gemini SDK/configuration has been removed from the project.
